# 🏦 Banking System – Java Console Application

## 📌 Project Description
This is a **single-file Java console application** that performs basic banking operations.  
The project allows a user to create an account, log in using a PIN, deposit and withdraw money, check balance, and view transaction history.  
All functionality is implemented in **one Java file**.

---

## 📄 File Details
BankingSystem.java
- Contains:
  - `BankAccount` class
  - `BankingSystem` (main class)

---

## ⚙️ Features
- Account creation with account number, name, and PIN  
- Secure login using PIN  
- Deposit money  
- Withdraw money with balance validation  
- Check current balance  
- View transaction history  
- Transaction history stored in a text file  

---

## 🛠️ Technologies Used
- Java  
- Core Java concepts:
  - Object-Oriented Programming
  - File Handling
  - Exception Handling
  - Scanner for user input

---

## ▶️ How to Run
1. Install Java JDK  
2. Save the file as `BankingSystem.java`  
3. Compile the program:
   ```bash
   javac BankingSystem.java

---
   
## Program Flow

1.User enters account details and sets a PIN

2.User logs in using the PIN

3.Banking menu is displayed:

4.Deposit

5.Withdraw

6.Check Balance

7.View Transactions

8.Exit
